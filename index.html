Configurar Google Sheets

Integração simples via URL publicada

Como configurar

  1. 1
    Crie uma planilha no Google Sheets

    Com as colunas: materia | topico | status | nota | data

  2. 2
    Publique a planilha

    Arquivo → Compartilhar → Publicar na web → CSV

  3. 3
    Cole a URL abaixo

    A URL de publicação CSV será usada para leitura.

  4. 4
    Para escrita (opcional)

    Use um Google Apps Script como webhook e cole a URL do script.

URLs de Integração

Template do Apps Script

function doPost(e) {
  var sheet = SpreadsheetApp.getActive()
              .getSheetByName("Página1");
  var data = JSON.parse(e.postData.contents);
  
  // Busca linha existente pelo tópico
  var rows = sheet.getDataRange().getValues();
  for (var i = 1; i < rows.length; i++) {
    if (rows[i][1] === data.topico) {
      sheet.getRange(i+1, 3).setValue(data.status);
      sheet.getRange(i+1, 4).setValue(data.nota);
      sheet.getRange(i+1, 5).setValue(data.data);
      return ContentService.createTextOutput("ok");
    }
  }
  // Se não existe, adiciona nova linha
  sheet.appendRow([data.materia, data.topico,
                   data.status, data.nota, data.data]);
  return ContentService.createTextOutput("ok");
}
